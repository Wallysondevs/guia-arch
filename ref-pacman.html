Referência: pacman × apt × dnf

Uma página para consultar, não para ler de cima a baixo. Na primeira parte, as ações comuns de pacotes em quatro famílias de distribuições, lado a lado. Na segunda, as flags do pacman agrupadas por operação, cada uma com um exemplo e a aula que a explica.

Como ler o pacman

Todo comando do pacman tem uma operação (letra maiúscula) e zero ou mais opções (minúsculas), que podem ser grudadas: -Syu = -S + -y + -u. As operações: -S sync (repositórios), -R remove, -Q query (o que está instalado), -U upgrade (arquivo local), -F files, -D database, -T deptest. A mesma letra minúscula muda de sentido conforme a operação: -Ss é search, -Rs é recursive. Em dúvida: pacman -S -h, pacman -Q -h… (ajuda em português) ou man pacman.

Duas regras que valem para toda a tabela

1. Comandos que mudam o sistema precisam de sudo (omitido nas tabelas). 2. No Arch, nunca atualize a lista sem atualizar o sistema: pacman -Sy pacote é uma atualização parcial. Use pacman -Syu (ou pacman -Syu pacote). Veja Atualizar o Sistema.

Flags do pacman, por operação

Exemplos reais da VM do guia quando o resultado é curto:

$ pacman -Qo /usr/bin/ls

    Lightweight HTTP server and IMAP/POP3 proxy server
$ pacman -Ss '^htop$'

    Interactive process viewer
$ pacman -Qdt
$ echo $?
1                                            « nenhum órfão (lista vazia = código 1)

downgrade 12.0.4-1
paru-bin 2.1.0-1
yay-bin 13.0.1-1
yay-bin-debug 13.0.1-1                       « vieram do AUR, não de um repositório

127

base-devel é meta-pacote, não grupo 
$ pacman -Sg base-devel
erro: grupo de pacotes "base-devel" não foi encontrado

Tutoriais antigos mostram pacman -S base-devel perguntando quais membros instalar. Hoje ele é um meta-pacote: instala tudo, sem perguntar.
