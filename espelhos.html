Espelhos (reflector)

Os pacotes do Arch não vêm de um servidor só. Universidades, empresas e voluntários do mundo todo mantêm espelhos (mirrors): cópias completas dos repositórios, atualizadas de hora em hora. Escolher bons espelhos, perto de você e em dia, deixa as atualizações rápidas e evita erros. O reflector faz essa escolha por você.

Você vai aprender
  • O arquivo /etc/pacman.d/mirrorlist e como o pacman usa a lista.
  • Gerar uma lista com o reflector: --country, --protocol, --latest, --sort, --save.
  • Deixar a lista sempre atualizada com o reflector.timer.
  • O rankmirrors, e o que fazer com espelho fora do ar ou desatualizado (pacman -Syy).

O mirrorlist

Em pacman: o Básico você viu que cada repositório do /etc/pacman.conf tem a linha Include = /etc/pacman.d/mirrorlist. Esse arquivo é a lista de servidores. Este é o da VM do guia, gerado pelo reflector durante a instalação:

################################################################################
################# Arch Linux mirrorlist generated by Reflector #################
################################################################################

# With:       reflector --country Brazil --protocol https --latest 5 --sort rate --save /etc/pacman.d/mirrorlist
# When:       2026-10-16 15:02:14 UTC
# From:       https://archlinux.org/mirrors/status/json/
# Retrieved:  2026-10-16 15:01:55 UTC
# Last Check: 2026-10-16 14:40:28 UTC

Server = https://mirror.ufscar.br/archlinux/$repo/os/$arch
Server = https://br.mirrors.cicku.me/archlinux/$repo/os/$arch
Server = https://archlinux.c3sl.ufpr.br/$repo/os/$arch
Server = https://mirrors.ic.unicamp.br/archlinux/$repo/os/$arch
Server =
Um espelho. O pacman tenta na ordem: o primeiro; se falhar, o segundo, e assim por diante.
$repo
Trocado pelo nome do repositório (core, extra). Não é variável do Bash: quem troca é o pacman.
$arch
Trocado pela arquitetura (x86_64).
# …
Comentários. O cabeçalho conta como a lista foi gerada (comando, data). Um #Server = é um espelho desligado.

Assim, para baixar o htop do extra, o pacman monta https://mirror.ufscar.br/archlinux/extra/os/x86_64/htop-3.5.3-1-x86_64.pkg.tar.zst. Como a lista é lida de cima para baixo, a ordem importa: o primeiro deve ser o mais rápido e confiável.

O que faz um espelho ser bom

Atualizado (sincronizou com o servidor principal há pouco tempo), rápido (perto de você, com boa banda) e seguro (HTTPS). Um espelho desatualizado é pior que um lento: ele oferece versões velhas, que podem não bater com as do resto do sistema. A situação de cada espelho é pública em archlinux.org/mirrors/status.

reflector: gerar a lista

O reflector (pacote reflector) baixa a situação de todos os espelhos do site do Arch, filtra, ordena e escreve a lista. Ele está no ambiente live da ISO (e roda sozinho lá no boot) e é o que se usa na instalação. As opções principais:

--country Brazil
Só espelhos desses países (nome em inglês ou código: BR; vários separados por vírgula: BR,US).
--protocol https
Só espelhos com esse protocolo (https, http, rsync).
--latest 5
Fica com os 5 que sincronizaram mais recentemente.
--sort rate
Ordena pela velocidade medida agora, baixando um arquivo de cada espelho. --sort age ordena pela última sincronização (não baixa nada, é instantâneo).
--save /etc/pacman.d/mirrorlist
Grava no arquivo (precisa de root). Sem --save, só mostra na tela.

Primeiro, quais países existem e quantos espelhos cada um tem:

$ reflector --list-countries | head -3
Country              Code Count
-------------------- ---- -----
Albania                AL     1
$ reflector --list-countries | grep -i -E "brazil|portugal"
Brazil                 BR    11                    « 11 espelhos no Brasil (de todos os protocolos)
Portugal               PT     8

Agora, uma lista sem gravar (sem --save, qualquer usuário pode rodar), ordenada por idade:

$ reflector --country BR --protocol https --latest 5 --sort age
################################################################################
################# Arch Linux mirrorlist generated by Reflector #################
################################################################################

# With:       reflector --country BR --protocol https --latest 5 --sort age
# When:       2026-10-16 16:28:13 UTC
# From:       https://archlinux.org/mirrors/status/json/
# Retrieved:  2026-10-16 16:28:13 UTC
# Last Check: 2026-10-16 16:18:23 UTC

Server = https://mirror.ufscar.br/archlinux/$repo/os/$arch
Server = https://mirrors.ic.unicamp.br/archlinux/$repo/os/$arch
Server = https://archlinux.c3sl.ufpr.br/$repo/os/$arch
Server = https://br.mirrors.cicku.me/archlinux/$repo/os/$arch

Pedimos 5, vieram 4: só 4 espelhos brasileiros com HTTPS estavam em dia naquele momento. O reflector nunca inventa espelhos para completar o número.

Gravar, medindo a velocidade

Este é o comando real da instalação da VM (no ambiente live, como root), com --sort rate e --save:

#> reflector --country Brazil --protocol https --latest 5 --sort rate --save /etc/pacman.d/mirrorlist
[2026-10-16 15:02:03] WARNING: failed to rate http(s) download (https://archlinux.c3sl.ufpr.br/extra/os/x86_64/extra.db): Download timed out after 5 second(s).
[2026-10-16 15:02:09] WARNING: failed to rate http(s) download (https://mirrors.ic.unicamp.br/archlinux/extra/os/x86_64/extra.db): Download timed out after 5 second(s).

Os dois WARNING (avisos) dizem que o reflector não conseguiu medir dois espelhos: o download de teste (o extra.db, de uns 8,5 MiB) não terminou em 5 segundos. Não é erro (o código de saída foi 0): esses espelhos foram para o fim da lista, que é exatamente a ordem do mirrorlist mostrado no começo da aula (c3sl e unicamp por último). Se a sua internet é lenta e todos dão esse aviso, aumente o tempo: --download-timeout 15.

ageSincronização mais recenteNenhum

Antes de gravar por cima

--save substitui o arquivo inteiro. Guarde uma cópia: sudo cp /etc/pacman.d/mirrorlist /etc/pacman.d/mirrorlist.bak. E depois de trocar a lista, rode sudo pacman -Syyu (veja abaixo por que dois y).

Lista sempre atualizada: reflector.timer

Espelhos mudam: saem do ar, ficam lentos, atrasam. O pacote traz um serviço e um timer do systemd que regeneram a lista toda semana. As opções ficam num arquivo, uma por linha, em /etc/xdg/reflector/reflector.conf. O padrão da VM:

# Reflector configuration file for the systemd service.
#
# Empty lines and lines beginning with "#" are ignored.  All other lines should
# contain valid reflector command-line arguments. The lines are parsed with
# Python's shlex modules so standard shell syntax should work. All arguments are
# collected into a single argument list.
#
# See "reflector --help" for details.

# Recommended Options

# Set the output path where the mirrorlist will be saved (--save).
--save /etc/pacman.d/mirrorlist

# Select the transfer protocol (--protocol).
--protocol https

# Select the country (--country).
# Consult the list of available countries with "reflector --list-countries" and
# select the countries nearest to you or the ones that you trust. For example:
# --country France,Germany

# Use only the  most recently synchronized mirrors (--latest).
--latest 5

# Sort the mirrors by synchronization time (--sort).
--sort age

Repare que a linha --country vem comentada: sem ela, o reflector escolhe entre os espelhos do mundo todo. Para o Brasil, acrescente --country BR (ou BR,US, para ter reserva). O serviço lê esse arquivo:

$ systemctl cat reflector.service --no-pager | grep ExecStart
ExecStart=/usr/bin/reflector @/etc/xdg/reflector/reflector.conf      « o @ = "leia as opções deste arquivo"
$ systemctl status reflector.timer --no-pager
○ reflector.timer - Refresh Pacman mirrorlist weekly with Reflector.
     Loaded: loaded (/usr/lib/systemd/system/reflector.timer; disabled; preset: disabled)
     Active: inactive (dead)                                          « vem desligado
    Trigger: n/a
   Triggers: ● reflector.service

O timer roda OnCalendar=weekly com RandomizedDelaySec=12h (um atraso aleatório de até 12 horas, para os computadores do mundo não baterem nos servidores ao mesmo tempo). Para ligar e testar uma vez agora (ilustrativo: na VM do guia ele fica desligado):

$ sudoedit /etc/xdg/reflector/reflector.conf      « acrescente: --country BR
$ sudo systemctl enable --now reflector.timer
$ sudo systemctl start reflector.service         « gera a lista agora, sem esperar a semana

rankmirrors: ordenar a lista que você já tem

O rankmirrors (do pacman-contrib) não busca espelhos novos: ele mede os que estão num arquivo e devolve a lista ordenada pela velocidade. Útil quando você montou a lista à mão ou quer reordenar sem trocar de espelhos. Saída real, com -n 0 (manter todos) e -v (mostrar os tempos):

$ rankmirrors -n 0 -v /etc/pacman.d/mirrorlist
# Server list generated by rankmirrors on 2026-10-16
…                                                                   « (o cabeçalho antigo é repetido)
# https://mirror.ufscar.br/archlinux/$repo/os/$arch ... 0.361154       « segundos para baixar o core.db
# https://br.mirrors.cicku.me/archlinux/$repo/os/$arch ... 0.296434    « o mais rápido
# https://archlinux.c3sl.ufpr.br/$repo/os/$arch ... 0.357783
# https://mirrors.ic.unicamp.br/archlinux/$repo/os/$arch ... 0.390736
Server = https://br.mirrors.cicku.me/archlinux/$repo/os/$arch
Server = https://archlinux.c3sl.ufpr.br/$repo/os/$arch
Server = https://mirror.ufscar.br/archlinux/$repo/os/$arch
Server = https://mirrors.ic.unicamp.br/archlinux/$repo/os/$arch

Ele mede baixando o pequeno core.db (uns 128 KiB), por isso os tempos são curtos e a ordem pode mudar de uma vez para outra. A saída vai para a tela; para gravar, redirecione para um arquivo temporário e depois mova como root (rankmirrors -n 5 lista > /tmp/nova; sudo mv /tmp/nova /etc/pacman.d/mirrorlist). Não use > /etc/pacman.d/mirrorlist direto: o Bash esvaziaria o arquivo antes de o rankmirrors lê-lo.

Trocou de espelho? pacman -Syy

O y do -Syu baixa o catálogo só se o do espelho for mais novo que o seu. Mas, ao trocar de espelho, o novo pode estar "atrás" do antigo, e o pacman acharia que não precisa baixar nada. O yy força baixar o catálogo de novo, mesmo que pareça em dia. Saídas reais, numa cópia do banco de dados:

$ sudo pacman -Sy
:: Sincronizando a base de dados de pacotes...
 core está atualizado                       « um y: nada mudou, nada baixado
 extra está atualizado
$ sudo pacman -Syy
:: Sincronizando a base de dados de pacotes...
 core                  127,9 KiB   340 KiB/s 00:00 [######################] 100%    « yy: baixa de novo
 extra                   8,5 MiB  3,70 MiB/s 00:02 [######################] 100%

Use -Syyu só depois de trocar de espelho (ou de um erro de catálogo corrompido). No dia a dia, é desperdício: baixa 8,6 MiB à toa e pesa nos espelhos, que são mantidos por voluntários. E lembre: -Sy ou -Syy sem o u só é seguro se o próximo passo for atualizar (veja Atualizar o Sistema).

Quando não funciona

Espelho fora do ar ou endereço errado

Para reproduzir sem estragar a VM, usamos uma lista de teste com um espelho que não existe e um endereço errado num espelho real, numa cópia do banco. A saída é real:

#> pacman -Sy
:: Sincronizando a base de dados de pacotes...
 core sendo baixado...
 extra sendo baixado...
erro: falha ao obter o arquivo "core.db" de espelho-que-nao-existe.example : Could not resolve host: espelho-que-nao-existe.example
atenção: erro fatal de espelho-que-nao-existe.example, ignorando o restante desta transação
erro: falha ao obter o arquivo "extra.db" de espelho-que-nao-existe.example : Could not resolve host: espelho-que-nao-existe.example
erro: falha ao obter o arquivo "core.db" de mirror.ufscar.br : The requested URL returned error: 404
erro: falha ao obter o arquivo "extra.db" de mirror.ufscar.br : The requested URL returned error: 404
erro: falha ao sincronizar todas as bases de dados (falha ao obter alguns arquivos)
MensagemCausa provável
Could not resolve hostNome do espelho errado, espelho extinto, ou sem DNS/internet (teste ping archlinux.org).
The requested URL returned error: 404O endereço está errado (caminho com erro na linha Server) ou o espelho apagou o arquivo.
Operation too slow / Connection timed outEspelho lento ou sobrecarregado.
erro fatal de …, ignorando o restanteO pacman desistiu daquele espelho nesta execução e passou para o próximo da lista.

Como resolver: confira a internet; depois gere uma lista nova com o reflector e rode sudo pacman -Syyu. Se tudo falhar ao mesmo tempo, veja se o problema não é geral em status.archlinux.org.

Downloads lentos no meio da instalação

No pacstrap da VM, o primeiro espelho engasgou em dois pacotes (saída real; o ambiente live fala inglês):

error: failed retrieving file 'linux-firmware-broadcom-20260916-1-any.pkg.tar.zst' from mirror.ufscar.br : Operation too slow. Less than 1 bytes/sec transferred the last 10 seconds
error: failed retrieving file 'vim-runtime-9.2.1178-1-x86_64.pkg.tar.zst' from mirror.ufscar.br : Operation too slow. Less than 1 bytes/sec transferred the last 10 seconds

O que aconteceu: o pacman desistiu daquele espelho para esses arquivos e os baixou do próximo da lista. A instalação terminou normalmente.

Como resolver: nada, se terminou. Se acontecer sempre, tire o espelho do topo ou rode o reflector com --sort rate.

"error: no mirrors found" 
$ reflector --country Brasil --latest 5
error: no mirrors found
$ echo $?
1

O que aconteceu: o país precisa ser o nome em inglês (Brazil) ou o código (BR). Filtros demais juntos também zeram a lista.

Como resolver: confira o nome com reflector --list-countries.

Pacote 404 só num pacote, com o catálogo em dia

O que aconteceu: o espelho está desatualizado: o seu catálogo (de um espelho mais novo) pede uma versão que esse ainda não tem, ou que já apagou.

Como resolver: gere a lista com --latest ou --sort age, para ficar com espelhos em dia, e rode sudo pacman -Syyu.

Resumo

  • /etc/pacman.d/mirrorlist: lista de Server =, usada de cima para baixo; $repo e $arch são trocados pelo pacman.
  • Bom espelho = atualizado, rápido, HTTPS. Situação em archlinux.org/mirrors/status.
  • reflector -c BR -p https -l 5 --sort rate --save /etc/pacman.d/mirrorlist; avisos de "failed to rate" não são erro.
  • reflector.timer + reflector.conf mantêm a lista em dia (vem desligado e sem país).
  • Depois de trocar de espelho: sudo pacman -Syyu.
