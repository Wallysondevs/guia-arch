Projeto: Montar um Desktop KDE

Depois da instalação, o Arch dá boot numa tela preta com notebook login:. Neste projeto você transforma essa instalação mínima num desktop KDE Plasma completo: interface, tela de login, vídeo, som, fontes, navegador e loja de aplicativos. Cada peça é uma decisão sua, e é por isso que o resultado fica do seu jeito.

Você vai praticar
  • Instalar um meta-pacote grande e responder às perguntas de provedor do pacman com consciência.
  • Escolher drivers de vídeo (mesa, Vulkan, NVIDIA).
  • Habilitar um gerenciador de login com systemctl enable.
  • Montar o som com PipeWire e WirePlumber, e escolher fontes.
  • Instalar aplicativos pelo pacman e pelo Flatpak.
O que é real e o que é ilustrativo nesta página

A VM do guia é compartilhada e não tem interface gráfica, então o desktop não foi instalado nela. Todas as listas de pacotes, perguntas e tamanhos abaixo são reais: vieram do previa, que roda a transação de verdade e responde "não" no fim (outubro de 2026). As partes que acontecem na tela gráfica (login, configurações do Plasma) são ilustrativas e estão marcadas.

Passo 2: o Plasma e suas perguntas

plasma-meta
Meta-pacote: um pacote vazio (7,13 KiB) que só depende das peças do Plasma (cerca de 65). Instalar o meta-pacote = instalar o Plasma completo; e, ao contrário de um grupo, ele acompanha peças novas que o KDE acrescentar no futuro.
sddm
O gerenciador de login clássico do KDE.
konsole
O terminal do KDE (o Plasma não traz terminal!).
dolphin
O gerenciador de arquivos do KDE (também não vem no Plasma).

plasma-meta, grupo plasma ou kde-applications-meta?

plasma-meta (meta-pacote) e o grupo plasma (68 pacotes; o pacman pergunta quais você quer) instalam o ambiente. kde-applications-meta instala todos os aplicativos do KDE (jogos, educação, PIM…): são centenas de pacotes a mais. Prefira o Plasma + os aplicativos que você usa.

Passo 4: a tela de login

Até aqui, nada gráfico liga sozinho (no Arch, nenhum serviço liga sozinho). Você precisa habilitar um gerenciador de login:

sudo systemctl enable sddm.service
# na próxima vez que ligar, a tela de login gráfica aparece
sudo reboot
SDDM ou Plasma Login Manager?

As versões recentes do Plasma ganharam um gerenciador de login próprio do KDE, e o plasma-meta já o puxa como dependência: o pacote plasma-login-manager, com o serviço plasmalogin.service. O SDDM continua disponível e é o que a maioria dos tutoriais usa. Os dois funcionam; habilite só um. Dois gerenciadores de login habilitados disputam a tela e o resultado é imprevisível.

sudo systemctl enable plasmalogin.service

Por que enable e não enable --now? Ligar a interface gráfica no meio de uma sessão de texto funciona, mas reiniciar garante que tudo (drivers, grupos, variáveis) comece limpo. Na tela de login, confira no canto o tipo de sessão: Plasma (Wayland) é o padrão e o recomendado; "Plasma (X11)" existe para casos especiais.

Passo 5: som com PipeWire

O PipeWire é o servidor de som (e de vídeo, para compartilhar tela) atual. Ele "finge ser" os sistemas antigos para os programas antigos funcionarem: pipewire-pulse imita o PulseAudio, pipewire-jack imita o JACK, pipewire-alsa atende programas ALSA. O WirePlumber é o "gerente de sessão": decide para onde vai cada som (caixas, fone, HDMI, Bluetooth).

$ pacman -Q pipewire wireplumber
pipewire 1:1.6.9-1
erro: o pacote "wireplumber" não foi encontrado

Na VM sem desktop, só o pipewire (biblioteca) está instalado; o wireplumber e o pipewire-pulse vêm com o Plasma, como a lista do passo 2 mostrou. Eles rodam como serviços do usuário (systemctl --user), ativados sozinhos quando você faz login. Para conferir, no Konsole (ilustrativo):

systemctl --user status pipewire pipewire-pulse wireplumber
wpctl status          # dispositivos e volumes, do WirePlumber

Notebooks recentes com placa de som Intel às vezes precisam de sof-firmware (sem ele: "Dummy Output", sem som). Para microfone e fone Bluetooth: sudo systemctl enable --now bluetooth.

Pelo Flatpak: a loja

O Plasma traz o Discover (a "loja") e o flatpak-kcm (permissões de Flatpak nas Configurações). O Flatpak do Arch vem sem o Flathub; na VM ele foi adicionado assim (log real da preparação):

#> flatpak remote-add --if-not-exists flathub https://dl.flathub.org/repo/flathub.flatpakrepo
#> flatpak remotes
flathub	system

Daí em diante, o Discover mostra os apps do Flathub, e você pode instalar pelo terminal: flatpak install flathub org.libreoffice.LibreOffice. Quando usar pacman e quando usar Flatpak está em Flatpak.

Passo 8: o primeiro login (ilustrativo)

  1. Reinicie: a tela do SDDM aparece. Escolha a sessão Plasma (Wayland), digite a senha.
  2. Configurações do Sistema → Região e idioma: confira Português (Brasil). O teclado gráfico é configurado à parte do console: Configurações → Teclado → Leiautes → Português (Brasil).
  3. Abra o Konsole e atualize: sudo pacman -Syu. O Discover também avisa de atualizações; no Arch, prefira o terminal para os pacotes do sistema e deixe o Discover para Flatpaks.
  4. Tire um snapshot da VM: "desktop-pronto".

Desfazer

O jeito mais limpo é restaurar o snapshot "antes-desktop". Sem snapshot: sudo systemctl disable sddm, depois sudo pacman -Rns plasma-meta sddm konsole dolphin firefox (o -s leva as dependências que ninguém mais usa; confira a lista antes de confirmar). Veja Cache e Órfãos para o que sobrar.

Quando não funciona

Reiniciei e continua a tela preta de texto

O que aconteceu: o gerenciador de login não foi habilitado.

Como confirmar: systemctl is-enabled sddm → disabled.

Como resolver: entre no texto, sudo systemctl enable --now sddm.

Tela preta com cursor depois do login (NVIDIA)

O que aconteceu: driver NVIDIA ausente ou sem o modo DRM (o nvidia-open atual já liga nvidia_drm.modeset=1).

Como resolver: Ctrl+Alt+F3 para um console de texto, confira pacman -Q nvidia-open nvidia-utils e o kernel (com linux-lts, use nvidia-open-dkms), veja journalctl -b -p err. Veja Quando o Sistema Trava.

Sem som / "Dummy Output"

O que aconteceu: falta firmware da placa de som (sof-firmware) ou o PipeWire não subiu.

Como resolver: sudo pacman -S sof-firmware e reinicie; systemctl --user status wireplumber.

Caracteres como quadradinhos

O que aconteceu: falta fonte para aquele alfabeto ou para emojis.

Como resolver: noto-fonts, noto-fonts-cjk, noto-fonts-emoji.

Resumo

  • sudo pacman -S plasma-meta sddm konsole dolphin: 438 pacotes, 612 MiB de download.
  • Responda às perguntas de provedor: ffmpeg, pipewire-jack, noto-fonts, tesseract-data-por.
  • Driver: mesa + vulkan-intel/vulkan-radeon, ou nvidia-open.
  • sudo systemctl enable sddm (ou plasmalogin, nunca os dois) e reinicie.
  • Som: PipeWire + WirePlumber, como serviços do usuário. Apps: pacman e Flatpak (adicione o Flathub).
