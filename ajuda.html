Arch Obtendo Ajuda

Ninguém decora as opções de todos os comandos. Quem usa Linux há anos consulta a ajuda o tempo todo. No Arch isso é ainda mais verdade: a distribuição espera que você leia. Nesta aula você aprende onde procurar dentro da própria máquina (o --help, o manual man, o help, o info, a busca por assunto) e fora dela (o tldr e a Arch Wiki). Todas as saídas vêm de um Arch real.

Você vai aprender
  • Usar --help para um resumo rápido e ler a linha "Uso".
  • Abrir, navegar e pesquisar no manual com man, e por que no Arch ele precisa dos pacotes man-db e man-pages.
  • Entender as seções do manual (man 5 passwd).
  • Usar help para os comandos internos do Bash e info para os manuais GNU.
  • Achar um comando pelo assunto com whatis e apropos, e consertar o "nada apropriado" com mandb.

--help: o resumo rápido

Quase todo comando aceita a opção --help, que mostra a forma de usar e as opções. Com o Arch em português, os programas GNU respondem traduzidos:

ls
O comando sobre o qual você quer ajuda.
--help
A opção que pede o resumo de uso.
| head -12
Corta nas 12 primeiras linhas: o texto completo do ls tem 184.
$ ls --help | head -12
Uso: ls [OPÇÃO]... [ARQUIVO]...
Lista informações sobre os ARQUIVOs (no diretório atual por padrão).
Lista as entradas em ordem alfabética se não for usada nenhuma opção -cftuvSUX
nem --sort.

Argumentos obrigatórios para opções longas também o são para opções curtas.
  -a, --all
         não ignora entradas começando com .
  -A, --almost-all
         não lista as entradas implícitas . e ..
      --author
         com -l, exibe o autor de cada arquivo

Para ler tudo com rolagem, use ls --help | less (setas para rolar, q para sair).

Como ler a linha "Uso"

Na ajudaSignifica

<pacote(s)>Entre sinais de menor/maior: obrigatório (estilo do pacman).
...Pode repetir: várias opções, vários arquivos.

man: o manual

O man (de manual) abre a página de manual de um comando. No Arch, ele não faz parte do sistema mínimo: o pacote base não traz nem o programa man nem as páginas. São dois pacotes:

PacoteO que traz
man-dbO programa man e seus companheiros (whatis, apropos, mandb).
man-pagesAs páginas do projeto Linux man-pages: chamadas do kernel, bibliotecas, arquivos (man 5 …), convenções (man 7 …) e as páginas POSIX (1p, 3p).

Na máquina deste guia os dois já estão instalados, porque foram incluídos no pacstrap durante a instalação, como a Arch Wiki recomenda (veja Espelhos e pacstrap):

#> pacstrap -K /mnt base linux linux-firmware intel-ucode networkmanager sudo nano vim man-db man-pages texinfo grub efibootmgr openssh
$ pacman -Q man-db man-pages
man-db 2.13.1-2
man-pages 6.19-1
$ pacman -Qo /usr/bin/man
/usr/bin/man pertence a man-db 2.13.1-2

Se você instalou sem eles, o man responde bash: man: comando não encontrado. Resolve-se com sudo pacman -S man-db man-pages (veja pacman: o Básico).

$ man ls

Repare: o --help do ls vem em português, mas o man ls vem em inglês. São fontes diferentes: o --help é traduzido junto com o programa; as páginas de manual em português ficam num pacote à parte, man-pages-pt_br, que não está instalado. A maioria das páginas do Arch é em inglês, e isso é normal.

Navegando dentro do man

O manual abre no leitor less, que ocupa a tela toda. As teclas principais:

TeclaO que faz
Espaço / bDesce / sobe uma página
↓ / ↑ (ou j / k)Desce / sobe uma linha
/texto EnterProcura "texto" para baixo
?texto EnterProcura "texto" para cima
n / NPróxima / anterior ocorrência da busca
g / GVai para o começo / fim
hAjuda do leitor (todas as teclas)
qSai do manual
Dica: buscar uma opção

Para achar a explicação do -h do ls, abra man ls, digite /-h e aperte Enter. Repita com n até chegar na linha certa. Para cair direto na definição, procure com os espaços do começo da linha: /^ *-h.

As seções do manual

O manual é dividido em seções numeradas. A tabela abaixo vem do próprio man man, que no Arch está traduzido (a tradução vem dentro do man-db):

$ man man
…
     A  tabela  abaixo mostra os números seção do manual seguido pelos tipos de
     páginas que eles contêm.

     1   Comandos shell ou programas executáveis
     2   Chamadas de sistema (funções fornecidas pelo kernel)
     3   Chamadas de biblioteca (funções dentro de bibliotecas de programa)
     4   Arquivos especiais (geralmente localizados em /dev)
     5   Formatos de arquivo e convenções, ex.: /etc/passwd
     6   Jogos
     7   Miscelânea (incluindo convenções e  pacotes  macro),  (ex.:    man(7),
         groff(7), man-pages(7))
…

No Arch você vai usar muito três delas: a 1 (comandos), a 5 (arquivos de configuração, como pacman.conf(5)) e a 8 (comandos de administração, como pacman(8)). Repare que o próprio pacman está na seção 8:

$ man pacman
PACMAN(8)                        Pacman Manual                        PACMAN(8)

NAME
     pacman - package manager utility

SYNOPSIS
     pacman <operation> [options] [targets]
…

O mesmo nome pode existir em várias seções. passwd, por exemplo, é um comando (seção 1) e também um arquivo (seção 5). Sem número, o man abre a primeira que encontrar; com número, você escolhe:

man
O manual.
5
A seção: formatos de arquivo.
passwd
O nome procurado: aqui, o arquivo /etc/passwd.
$ man 5 passwd
PASSWD(5)                     Formatos de Arquivo                     PASSWD(5)

NOME
     passwd - arquivo de senhas

DESCRIÇÃO
     Passwd  é  um  arquivo  texto,  que  contém  a lista de contas do sistema,
     fornecendo para cada conta qualquer  informação  útil  como  identificação
     numérica  do  usuário,  identificação  numérica  do  grupo,  diretório  do
     usuário, interpretador de comandos, etc.   Freqüentemente  ele  contém  as
…

Essa veio em português porque o pacote shadow traz a tradução. Para saber onde está o arquivo de cada página, use man -w (de where); com -a, todas as que existem:

$ man -a -w passwd
/usr/share/man/man1/passwd.1.gz
/usr/share/man/man1/openssl-cmds.1ssl.gz
/usr/share/man/pt_BR/man5/passwd.5.gz          « a tradução em português
/usr/share/man/man5/passwd.5.gz                « a original em inglês
$ pacman -Qo /usr/share/man/pt_BR/man5/passwd.5.gz
/usr/share/man/pt_BR/man5/passwd.5.gz pertence a shadow 4.20.0.arch1-1

Quando há tradução e original, o man escolhe pelo idioma do sistema (LANG=pt_BR.UTF-8). Para forçar o inglês (às vezes a tradução está desatualizada), use man -L C 5 passwd.

help: comandos internos do Bash

Alguns comandos não são programas separados: fazem parte do próprio Bash. São os comandos internos (builtins), como cd, pwd, echo e history. Eles não têm página de manual própria; a ajuda deles é o help. Você descobre o que é cada comando com type:

$ type cd ls echo pacman man help
cd é um comando interno do shell
ls está apelidada para `ls --color=auto'      « um alias do ~/.bashrc do Arch
echo é um comando interno do shell
pacman é /usr/bin/pacman                      « um programa: tem man e --help
man é /usr/bin/man
help é um comando interno do shell
help
O comando interno que mostra a ajuda dos outros comandos internos.
pwd
O comando sobre o qual você quer saber.
$ help pwd
pwd: pwd [-LP]
    Mostra o nome do diretório de trabalho atual.

    Opções:
      -L	mostra o valor de $PWD se ele tiver o nome do diretório de
      		trabalho atual
      -P	mostra o diretório físico, sem quaisquer links simbólicos

    Por padrão, `pwd' se comporta como se a opção `-L' foi especificada.

    Status de saída:
    Retorna 0, a menos que uma opção inválida seja fornecida ou o diretório
    atual não possa ser lido.

O Bash 5.3 do Arch traz a ajuda interna traduzida. O help sozinho lista todos os comandos internos. Nos comandos internos, cd --help também funciona e mostra o mesmo texto.

Missão: descubra se cd, ls e echo são comandos internos do shell, aliases ou programas, usando type. Dica: type aceita vários nomes de uma vez.

Missão: o pwd é interno do Bash. Mostre a ajuda dele com o comando certo para comandos internos.

info: os manuais GNU completos

Os programas do projeto GNU (coreutils, bash, grep, sed, tar…) têm um manual mais longo que a página man, no formato info. O leitor info vem no pacote texinfo, que também foi incluído no pacstrap da máquina do guia:

$ info ls
File: coreutils.info,  Node: ls invocation,  Next: dir invocation,  Up: Directory listing

10.1 ‘ls’: List directory contents
==================================

The ‘ls’ program lists information about files (of any type, including
directories).  Options and file arguments can be intermixed arbitrarily,
as usual.  Later options override earlier options that are incompatible.
…

A primeira linha mostra onde você está: o capítulo (node) "ls invocation" do manual do coreutils, com o próximo (Next) e o de cima (Up). Dentro do info: Espaço rola, n vai ao próximo capítulo, p ao anterior, u sobe, Enter segue um link (linhas com *) e q sai. Para o dia a dia, o man basta; o info é para quando você quer o livro inteiro.

whatis e apropos: procurar por assunto

O whatis mostra a descrição de uma linha (a parte NAME) de uma página. O apropos faz o contrário: procura uma palavra em todas as descrições. Os dois consultam um índice que o man-db mantém em /var/cache/man.

"nada apropriado" num Arch recém-instalado

Logo depois da instalação, eles parecem quebrados:

$ whatis ls
ls: nada apropriado.
$ apropos "list directory"
list directory: nada apropriado.
$ ls /var/cache/man                « vazio: o índice ainda não existe

O motivo: no Arch, quem monta esse índice é um timer do systemd, o man-db.timer, que roda uma vez por dia, num horário sorteado (até 12 horas de atraso). Numa máquina recém-instalada ele ainda não rodou:

$ systemctl list-timers man-db.timer --all
NEXT                        LEFT LAST                        PASSED UNIT         ACTIVATES
Sat 2026-10-17 02:40:14 -03  11h Fri 2026-10-16 12:12:00 -03      - man-db.timer man-db.service

1 timers listed.
$ journalctl -u man-db.service
-- No entries --                   « o serviço nunca rodou

Você não precisa esperar: o comando que monta o índice é o mandb, e como ele escreve em /var/cache/man, precisa de sudo:

sudo
Roda como administrador (o índice é do sistema).
mandb
Lê todas as páginas de manual e monta o índice que whatis e apropos consultam.
$ sudo mandb
[sudo] senha para ana:
Atualizando o cache de índice para o caminho "/usr/share/man/man2type". Aguarde...
Atualizando o cache de índice para o caminho "/usr/share/man/man6". Aguarde...
…
Processando as páginas de manual sob /usr/share/man...
mandb: aviso: /usr/share/man/man5/fapi-profile.5.gz: análise por whatis para fapi-profile(5) falhou
…
117 subdiretórios man continham páginas de manual novas.
27855 páginas de manual foram adicionadas.
0 cat errante foi adicionado.
0 entrada antiga no banco de dados foi descartada.

Na máquina do guia, a execução levou de um a alguns minutos (o disco faz diferença) e mostrou mais de mil linhas mandb: aviso: …. Esses avisos são inofensivos: são páginas (de bibliotecas como a xcb) sem a parte NAME no formato esperado, que só ficam de fora do índice. O que importa é o resumo final. Depois disso, a busca funciona:

$ whatis passwd

E depois?

Você só precisa rodar sudo mandb uma vez. A partir daí o man-db.timer atualiza o índice sozinho, todo dia, incluindo as páginas dos pacotes que você instalar.

tldr: exemplos prontos

O tldr (de too long; didn't read, "longo demais, não li") mostra só os exemplos mais usados de cada comando, sem a teoria. É uma ótima companhia para o man. Ele não vem instalado:

$ tldr tar
bash: tldr: comando não encontrado
$ echo $?
127

No repositório extra há dois programas que leem as mesmas páginas da comunidade tldr. Veja o que cada um instalaria (o resumo é real; aqui a resposta foi n, então nada foi instalado):

$ sudo pacman -S tldr

procurando pacotes conflitantes...

Pacotes (4) python-colorama-0.4.6-6  python-shtab-1.12.1-1
            python-termcolor-3.3.0-1  tldr-3.4.4-1

Tamanho total instalado:  0,68 MiB

:: Continuar a instalação? [S/n] n

procurando pacotes conflitantes...

Pacotes (1) tealdeer-1.9.0-1

Tamanho total download:   1,34 MiB

Depois de instalar, o primeiro uso baixa as páginas da internet (tldr --update), e tldr tar passa a mostrar uma lista curta de exemplos comentados. A máquina do guia não tem nenhum dos dois instalado, por isso a saída do tldr não aparece aqui.

A Arch Wiki

O man explica o programa; a Arch Wiki explica como usá-lo no Arch: que pacote instalar, que serviço ligar, que arquivo editar, que erro costuma aparecer. Ela é tão boa que usuários de outras distribuições também a leem. Toda aula deste guia termina com os links da Wiki sobre o tema.

A própria Wiki ensina a ler as suas páginas: o prompt $ indica um comando de usuário comum, e # indica um comando para root (no Arch, você o roda com sudo). A aula A Arch Wiki mostra como pesquisar, ler a página em português e usá-la sem internet.

Quando não funciona

"whatis: nada apropriado" para um comando que existe 
$ whatis ls
ls: nada apropriado.

O que aconteceu: o índice do man-db ainda não foi montado (instalação nova; o man-db.timer roda uma vez por dia).

Como confirmar: ls /var/cache/man vazio, ou journalctl -u man-db.service sem nenhuma entrada.

Como resolver: sudo mandb, uma vez.

"Nenhuma entrada de manual para…" 
$ man nadaexiste
Nenhuma entrada de manual para nadaexiste
$ echo $?
16
$ man 9 ls
Nenhuma entrada de manual para ls na seção 9

O que aconteceu: não há página com esse nome (ou não naquela seção). Pode ser erro de digitação, um comando interno do shell (use help), um programa sem manual ou um pacote cujas páginas não foram instaladas. O código 16 é o do man para "página não encontrada".

Como resolver: tente comando --help, help comando ou apropos palavra.

"bash: man: comando não encontrado"

O que aconteceu: o Arch foi instalado sem o man-db. O pacote base não o inclui.

Como resolver: sudo pacman -S man-db man-pages. Se quiser as páginas em português que existirem, acrescente man-pages-pt_br.

"bash: tldr: comando não encontrado"

O que aconteceu: o tldr não vem instalado.

Como resolver: sudo pacman -S tealdeer (ou tldr) e depois tldr --update.

"erro: opção inválida" ao pedir ajuda ao pacman 
$ pacman -s bash
erro: opção inválida "-s"

O que aconteceu: faltou a operação em maiúscula (veja Sintaxe dos Comandos).

Como resolver: pacman -h lista as operações; pacman -S -h lista as opções de -S.

Fiquei preso dentro do man (ou do info)

O que aconteceu: o manual abre num leitor que ocupa a tela toda.

Como resolver: aperte q.

Resumo

  • comando --help: resumo rápido, em português; no pacman, -h por operação.
  • man comando: manual completo (no Arch, pacotes man-db e man-pages, quase tudo em inglês).
  • No man, / procura, n repete e q sai; man 5 passwd escolhe a seção.
  • help para comandos internos (cd, pwd); type diz o que é cada comando; info para os manuais GNU.
  • whatis/apropos dizem "nada apropriado" até o índice existir: sudo mandb.
  • tldr (pacote tldr ou tealdeer) mostra exemplos; a Arch Wiki ensina a usar tudo no Arch.

Na Arch Wiki: o manual está em Man page (em português), que explica o man-db, o mandb, as páginas traduzidas e os leitores alternativos; o formato info, em Info; e como ler as convenções da própria Wiki ($, #, "instale o pacote…"), em Help:Reading (em português).
