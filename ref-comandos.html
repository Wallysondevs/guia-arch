Referência de Comandos

Todos os comandos que aparecem no guia, agrupados pelo que fazem. Cada linha tem o que o comando faz, um exemplo típico e a aula onde ele é explicado com calma. Para as flags do pacman, veja pacman × apt × dnf; para os termos, o Glossário.

Como usar esta página

Use a busca do navegador (Ctrl+F) para achar um comando. Os exemplos com sudo mudam o sistema: leia a aula antes de rodá-los. Quase todo comando tem manual: man comando (pacote man-db) ou comando --help.
