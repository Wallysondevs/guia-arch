Arch Quiz

Trinta e seis perguntas práticas: doze de cada nível. Cada uma corrige na hora; abra "Por quê?" para ver a explicação e o link para a aula. Quase todas pedem para interpretar uma situação ou uma saída real do terminal, não para decorar.

Acertos: 0 de 36

Nível 1 · Iniciante

1. O que quer dizer BUILD_ID=rolling no /etc/os-release do Arch?

Por quê?

No modelo rolling release não existe "Arch 2" ou "Arch 3": um pacman -Syu traz tudo para o estado atual. Revise: Rolling Release.

2. No ambiente live, você digitou isto. O que fazer?

#> loadkeys br-abnt3
loadkeys: Unable to open file: br-abnt3: No such file or directory
Por quê?

O mapa não existe com esse nome; o teclado brasileiro ABNT2 é br-abnt2. Revise: O Ambiente Live.

3. Qual partição a UEFI precisa para dar boot?

Por quê?

A UEFI só lê FAT; os bootloaders ficam na ESP. No guia: /dev/sda1, 1 GiB, montada em /boot. Revise: Particionar o Disco.

4. O pacstrap parou com isto. O que aconteceu?

error: target not found: networkmanger
==> ERROR: Failed to install packages to new root
Por quê?

"target not found" = o pacman não achou um pacote com esse nome. Nada foi instalado; corrija e repita. Revise: Espelhos e pacstrap.

5. O que faz o arch-chroot /mnt?

Por quê?

É assim que se configura fuso, idioma, usuários e bootloader do sistema novo, ainda dentro do live. Revise: Configurar o Sistema.

6. Depois de instalar um segundo kernel (linux-lts), o GRUB passou a iniciar com ele. Por quê?

Por quê?

Com dois kernels, a ordenação deixou o LTS em primeiro. GRUB_TOP_LEVEL="/boot/vmlinuz-linux" + grub-mkconfig resolve. Revise: Bootloader, Kernels.

7. A ana rodou isto. O que fazer?

$ pacman -S fastfetch
erro: você não pode realizar esta operação a menos que seja root.
Por quê?

Instalar muda o sistema e exige root. Revise: pacman: o Básico, sudo, root e Usuários.

8. Qual é o jeito certo de atualizar o Arch?

Por quê?

O Arch só suporta o sistema atualizado por inteiro; -Sy sem -u é atualização parcial. Revise: Atualizar o Sistema.

9. No Arch, qual grupo dá direito ao sudo (depois de descomentar a linha no sudoers)?

Por quê?

No Arch (e no Fedora) é wheel; o grupo sudo é do Debian/Ubuntu. Revise: sudo, root e Usuários.

10. O pacman parou com "não foi possível travar a base de dados" e pgrep -a pacman não mostra nada. O que fazer?

Por quê?

Sem outro pacman rodando, a trava é resto de um pacman interrompido (na VM do guia, um desligamento forçado). Só apague nessa situação. Revise: Atualizar.

11. Instalei o Arch e só aparece "notebook login:" numa tela preta. Deu errado?

Por quê?

É o sistema mínimo funcionando. Revise: Instalar um Desktop, Montar um Desktop KDE.

12. O sistema congelou totalmente. Qual a forma mais segura de reiniciar antes de apertar o botão?

Por quê?

REISUB pede ao kernel para encerrar processos, gravar o disco e desmontar antes de reiniciar. Revise: Quando o Sistema Trava.

Nível 2 · Intermediário

13. O que mostra pacman -Qdt?

Por quê?

-d = dependências, -t = não exigidos. Lista vazia devolve código 1. Revise: Cache e Órfãos.

14. Depois de uma atualização apareceu /etc/pacman.conf.pacnew. O que é?

Por quê?

O pacman nunca sobrescreve uma configuração que você mudou; compare com pacdiff. Revise: .pacnew e .pacsave.

15. Uma atualização falha com "a assinatura de … tem confiança desconhecida". Primeiro passo?

Por quê?

O chaveiro velho não conhece a chave de um empacotador novo. Nunca desligue a verificação. Revise: Chaves e Assinaturas.

16. Por que sudo pacman -S yay dá "alvo não encontrado"?

Por quê?

Do AUR se baixa a receita (git clone) e se constrói com makepkg -si. Revise: O que é o AUR, makepkg.

17. Antes de construir um pacote do AUR, o que você deve sempre fazer?

Por quê?

O AUR não tem revisão prévia; já houve pacotes com malware. Revise: AUR com Segurança.

18. Você deu sudo systemctl start sshd e, depois do reboot, o SSH não respondia. Por quê?

Por quê?

No Arch nenhum serviço liga sozinho; enable cria o link para o boot. Revise: systemctl e Serviços.

19. Qual comando mostra só as mensagens de erro do boot atual?

Por quê?

-b = este boot; -p err = prioridade erro ou pior. O Arch não tem /var/log/messages. Revise: Logs (journalctl).

20. O que este erro quer dizer?

$ systemd-analyze calendar 'segunda 08:00'
Failed to parse calendar specification 'segunda 08:00': Argumento inválido
Por quê?

O OnCalendar= entende Mon, Tue… Teste sempre com systemd-analyze calendar. Revise: Timers e Tarefas.

21. Qual a ordem segura para usar SSH só com chave?

Por quê?

Desligar a senha antes de testar a chave tranca você para fora. A chave privada nunca sai do cliente. Revise: SSH.

22. Você editou o /etc/fstab. Como testar antes de reiniciar?

Por quê?

mount -a monta tudo o que falta; um erro aparece agora, não no boot (que cairia no emergency mode). Revise: mount e fstab.

23. Depois de atualizar, o paru não abre: "error while loading shared libraries: libalpm.so.15". Por quê?

Por quê?

Pacotes do AUR não são reconstruídos pelo Arch quando uma biblioteca muda. Revise: yay e paru.

24. Para que serve o microcode (intel-ucode/amd-ucode)?

Por quê?

O fabricante corrige falhas da CPU por microcode; o bootloader o carrega antes do kernel. Revise: Microcode.

Nível 3 · Avançado

25. O que o snapper faz, com o hook do pacman, a cada atualização?

Por quê?

Os pares "pre/post" permitem desfazer uma atualização problemática. Revise: Snapshots (snapper).

26. Você usa raiz criptografada (LUKS) e o boot não pede a senha, caindo num shell de emergência. Suspeito número 1?

Por quê?

Quem pede a senha é o initramfs; sem o hook, ele nem tenta abrir o LUKS. Revise: Criptografia (LUKS), mkinitcpio.

27. O sistema não dá boot. Qual a sequência para consertar a partir do pendrive?

Por quê?

Dentro do chroot você roda pacman, mkinitcpio -P e grub-install como se estivesse no sistema. Revise: Resgate com chroot, Recuperar o Boot.

28. No PKGBUILD, o que vai na função package()?

Por quê?

Ordem: prepare(), build(), check(), package(). Nunca instale direto em /usr. Revise: Escrever um PKGBUILD.

29. No Arch, você procurou /etc/nginx/sites-enabled e não existe. Por quê?

Por quê?

Se quiser o estilo Debian, crie a pasta e um include no nginx.conf. Revise: Servidor Web (nginx).

30. O que esta saída diz?

$ podman top dorminhoco user huser pid args
USER        HUSER       PID         COMMAND
root        1000        1           sleep 600
Por quê?

USER é o usuário dentro do container; HUSER, no host. Revise: Docker e Podman.

31. Na VM do guia, ls -l /dev/kvm diz "Arquivo ou diretório inexistente" e systemd-detect-virt responde oracle. Conclusão?

Por quê?

/dev/kvm só existe com VT-x/AMD-V disponível; oracle = VirtualBox. Revise: Máquinas Virtuais (KVM).

32. No systemd-analyze blame, dev-sda1.device aparece com 16 s. O que concluir?

Por quê?

Unidades .device esperam junto com o resto; filtre com grep -v '\.device'. Revise: Desempenho.

33. A ana errou a senha 3 vezes num sudo. Agora a senha certa é recusada. O que está acontecendo?

Por quê?

Padrão do Arch: 3 falhas em 15 min = 10 min de bloqueio; faillock --user ana --reset (root) libera. Revise: Segurança.

34. Como testar um arquivo de regras do nftables sem aplicá-lo?

Por quê?

-c (check) confere a sintaxe e não muda nada; o erro aponta linha e coluna. Revise: Servidor Caseiro, Firewall.

35. Você escreveu um hook com nome errado no mkinitcpio.conf e viu isto. O que acontece se reiniciar assim?

==> ERROR: Hook 'filesytems' cannot be found
==> WARNING: errors were encountered during the build. The image may not be complete.
Por quê?

"The image may not be complete" é sério: sem o hook certo, o kernel pode não achar a raiz. Revise: mkinitcpio e initramfs.

36. O que o Manjaro muda de mais importante em relação ao Arch?

Por quê?

EndeavourOS usa os repositórios do Arch; o Manjaro, os seus. Os fóruns do Arch não dão suporte a derivadas. Revise: Arch × Debian × Fedora.
